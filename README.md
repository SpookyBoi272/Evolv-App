# Evolv Frontend

The Nuxt frontend is an interactive product prototype for Evolv, a creator-led learning platform. It includes a creator dashboard, course drafts, a knowledge library, human review gates, learner progress, and a learner lesson preview with adaptive explanation and confidence controls.

The prototype uses illustrative in-memory data. Source selection adds local file metadata only; it does not upload files or call an AI service. Connect these interactions to the API before using real creator or learner data.

## Run

```powershell
npm install
npm run dev
```
